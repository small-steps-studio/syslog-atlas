# Getting started

1. Install **Syslog Atlas** (publisher SmallStepsStudio) from the Extensions view.
2. Open a syslog or CEF log file (.log, auth.log, syslog, messages), or run **Syslog Atlas: Open Sample File** to open the invented sample.
3. Open the Command Palette (`Ctrl+Shift+P`, on macOS `Cmd+Shift+P`), type `Syslog Atlas` and pick a report. The button in the editor title bar of *.log files and syslog, messages, auth.log and secure runs **Show Log Summary**.
4. The report opens as a new Markdown document (and its preview). Save it, copy it into a ticket, or close it.
5. **Syslog Atlas: Open Walkthrough** shows the same steps inside the editor.

Every report is described in [reports.md](reports.md). Licence and trial: [licence.md](licence.md). Problems: [troubleshooting.md](troubleshooting.md).
